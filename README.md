# 🌊 2026 釜山五天四夜｜互動式客製行程規劃

**Live：https://kenhuangads.github.io/busan-trip/**

給老婆的釜山旅遊企劃網站：勾選想去的地方，自動排出專屬五天四夜行程表。

## 怎麼用

1. **勾選**：景點至少 4 個、餐飲至少 6 家（購物清單選填），可依分類與區域篩選。
2. **產生行程**：按「✨ 產生專屬行程」，依區域動線（西面／海雲台・機張／廣安里／南浦）自動編排 5 天時間軸，含航班、飯店、交通小抄與空檔推薦（推薦項目會清楚標示「未勾選」）。
3. **審核**：結果頁可「複製文字版」貼 LINE、「複製分享連結」（開啟連結即重現同一份行程）、或列印存 PDF。

## 固定資訊

- ✈️ 2026/9/26（六）08:10 台中 → 釜山｜9/30（三）15:00 釜山 → 台中（星宇航空）

- 內容取自 2026 釜山高端自由行深度市場與餐飲分析報告（116 個項目：10 景點、46 餐飲、60 購物）。
- 每個項目附 Google 地圖／NAVER 地圖／官網或商品介紹連結。
