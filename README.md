# 🌊 2026 釜山五天四夜｜互動式客製行程規劃

**Live：https://kenhuangads.github.io/busan-trip/**

兩人同行的釜山旅遊企劃網站：勾選想去的地方，自動排出專屬五天四夜行程表（含交通與時間試算）。

## 怎麼用

1. **勾選**：景點至少 4 個、餐飲至少 6 家（購物清單選填），可依分類與區域篩選，並可依「推薦度／價格／離飯店距離」排序。
2. **產生行程**：按「✨ 產生專屬行程」，依區域動線（西面／海雲台・機張／廣安里／南浦）自動編排 5 天時間軸：
   - 每個點標示**建議停留時間**（含排隊緩衝的保守估算）。
   - 每段移動顯示**出發／預計抵達時間**：預設計程車（含車資試算），當地鐵更順時自動改搭地鐵，短程則步行；空檔大於 25 分鐘會標示「自由時間」。
   - 勾選的購物項目會對應到**具體門市**（如 Olive Young 西面旗艦店、樂天超市光復店、新世界 Centum City）並以「繞路最少」原則排進當日行程；西面採買集中在 Day 5 上午。
3. **審核與同步**：結果頁可「複製文字版」貼 LINE、「複製分享連結」（開啟連結即重現同一份行程）、列印存 PDF；每次產生行程會自動存成**版本**（保留最近 10 版，可切換採用），並可透過「📊 Google 試算表」把任一版本同步到雲端試算表比較挑選（TSV 貼上／Google 表單免授權同步／Apps Script 三種方式）。
